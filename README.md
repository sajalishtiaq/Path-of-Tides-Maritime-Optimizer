# Path-of-Tides-Maritime-Optimizer
A comprehensive Data Structures semester project that simulates a real-world maritime route planning and optimization system with interactive visualization.

## Features

- Interactive world map with ports and shipping routes
- Dijkstra’s algorithm for shortest path (Cost-based & Time-based)
- Real-time ship animation along optimal routes with sound
- Custom ship booking and preferences (avoid/prefer companies & ports)
- Docking queue management using queues
- Subgraph generation with route filtering
- Multi-leg journey visualization
- Interactive tooltips and port information
- Zoom, pan, and smooth animations

## Technologies

- **Language**: C++
- **Graphics & Audio**: SFML 2.6.2
- **Data Structures**: Custom implementations only (LinkedList, Queue, Stack, MinHeap, HashMap)
- No STL containers used
